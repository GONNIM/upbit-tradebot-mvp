## 1️⃣ 오늘 일어난 일 — 사실 그대로

### 1-1. 코드/시스템은 정상

- 최신 코드가 서버에 정상 배포되어 있음
- 봇 서비스가 정상 작동 중 (오늘 저녁 8시 38분 재시작 후 안정 운영)
- 매매 조건 변경 시 **저장하면 다음 봉부터 자동 반영**되는 기능도 정상
- 지정가 매수가 **3봉(3분) 동안 체결 대기 후 자동 취소**되는 기능도 정상

### 1-2. 그런데 왜 손실이 났는가

오늘 매도가 작동한 흐름:

```
   매수 진입
     │
     ▼ (가격 하락 시작)
   -0.5% ──── 손절(Stop Loss) 꺼짐 → 그대로 통과
   -1.0% ──── 손절이 켜져 있었다면 여기서 컷
   -1.5%
   -2.0%
   -3.0%
   -4.0%
   -5.2% ──── EMA 데드 크로스(추세 하락 신호) 발생 → 그제서야 매도
```

→ **매도 안전망이 EMA 데드 크로스 하나뿐**이었고, 그 신호는 가격이 한참 떨어진 다음에야 발생하는 지연 신호다.

### 1-3. 손실 직후 사용자가 했던 조작의 함정

오늘 -5.226% 손실을 본 직후, 21시 49분에 매매 조건을 다시 저장했다. 그 안에서 사용자는:

```
손절 비율:  1.0%  →  0.5%   (값을 더 작게 줄임)
익절 비율:  2.5%  →  1.0%   (값을 더 작게 줄임)
```

값은 줄였지만 **"손절 / 익절" 토글 자체는 꺼진 그대로** 유지됐다.

이 화면 안에는 두 가지 별개 항목이 있다:
- **토글(켜기/끄기)** — "이 기능을 사용할 것인가" 여부
- **숫자(비율)** — "사용할 때 어떤 비율로 발동할 것인가" 값

**토글이 꺼져 있으면 숫자를 아무리 바꿔도 발동되지 않는다.**

손실 직후 자연스럽게 "더 안전하게 0.5%로 줄여야지" 라고 생각하지만,
실제로는 **안전장치 자체가 꺼져 있어서 어떤 숫자도 의미가 없는 상태**가 5일째 지속되고 있다.

## 2️⃣ 받아들여야 할 사실 세 가지

### ① 매도 안전망이 모두 꺼져 있다
- 손절(Stop Loss) ❌ 꺼짐
- 익절(Take Profit) ❌ 꺼짐
- 장기 보유 차단(Stale Position) ❌ 꺼짐

→ 가격이 -10%, -15%로 떨어져도 EMA 데드 크로스가 나기 전까진 매도되지 않는다.

### ② 숫자(0.5%)를 바꿔도 토글이 꺼져 있으면 효과가 없다
- "조건 설정" 화면은 토글과 숫자가 **별개의 입력 항목**으로 설계되어 있다.
- 토글이 꺼져 있으면 숫자는 그저 "켤 때 사용할 예정 값"으로 저장만 될 뿐 발동하지 않는다.

### ③ 6/21 진단 보고서의 8개 권장사항 중 적용된 것이 0개다
- 6월 21일 28일치 데이터를 분석한 결과 8개 개선 권장사항이 제시됐다.
- 그 권장사항 중 **단 하나도 매매 조건에 반영되지 않았다.**
- 인프라(시스템 코드) 개선은 끝났지만, 매매 조건은 사용자가 직접 화면에서 토글/숫자를 바꿔야만 적용된다.

## 3️⃣ 무엇을 바꿔야 하는가 — 6하원칙으로 정리

### 🧍 누가 (WHO)

**사용자 본인만 적용할 수 있다.**

- 봇은 매매 조건을 자기 마음대로 바꾸지 않는다.
- 매매 조건은 **대시보드의 "조건 설정" 화면**에서만 변경 가능하다.

### 🕐 언제 (WHEN)

**가능한 빠르게 — 다음 매수 신호가 발생하기 전에.**

- 1분봉 기준 EMA 골든 크로스(상승 신호)는 하루에도 수 차례 발생할 수 있다.
- 지금 상태로 매수가 한 번 더 일어나면 같은 패턴의 손실이 반복될 위험이 크다.
- **저장 즉시 다음 봉(1분)부터 자동 반영되므로, 적용에 필요한 시간은 클릭 1~2분이면 충분하다.**

### 🗺️ 어디서 (WHERE)

**대시보드의 "매수/매도 조건 설정" 화면.**

- 사용자: `mcmax33`

- 일부 항목(주문 비율 등)은 "설정(Config)" 화면에 위치.

### 🔧 어떻게 (HOW) — 단계별 적용

#### Step 1. 화면 진입

> 대시보드 → 좌측 메뉴 → **"매수/매도 조건 설정"** 클릭
> 사용자 = `mcmax33`, 전략 = `EMA` 선택 확인

#### Step 2. 매도 조건 5가지 조정

```
[매도 조건 섹션]

① 손절 (Stop Loss)
    ☐ → ☑ (켜기)
    비율:  0.5%  →  1.5%

② 익절 (Take Profit)
    ☐ → ☑ (켜기)
    비율:  1.0%  →  2.5%

③ 장기 보유 차단 (Stale Position)
    ☐ → ☑ (켜기)
    한계 시간:  90 분
    임계 손익: -0.3 %  (음수 입력)

④ 트레일링 스탑 발동 임계
    30%  →  15%
```

#### Step 3. 매수 조건 2가지 조정

```
[매수 조건 섹션]

⑤ 급등 필터 (Surge Filter)
    ☐ → ☑ (켜기)
    임계:  (현재 OFF)  →  2.5%

⑥ 양봉 매수 (Bullish Candle)
    ☐ → ☑ (켜기)
```

#### Step 4. 저장

> 화면 하단 **💾 저장** 버튼 클릭
> → 안내 메시지 확인:
> "✅ 설정이 저장되었습니다. 엔진은 다음 봉부터 자동 적용됩니다."

#### Step 5. 1~2분 안에 자동 반영 확인

> 대시보드 메인 화면으로 이동
> → **"엔진 현재 적용 조건"** 패널 확인
> → 표의 "엔진 적용중" 컬럼이 방금 저장한 값과 일치하는지 확인
> → 일치 = 정상 ✓
> → 만약 1분 더 기다려도 불일치하면 알려주기 (드물지만 가능)

### ❓ 왜 (WHY) — 각 항목의 트레이딩적 이유

| 항목 | 이유 |
|---|---|
| 손절 켜기 + 1.5% | **수익/손실 균형 회복의 핵심.** 0.5%는 평균 슬리피지(체결 미끄러짐)에 묻혀 잡음마다 매도되어 작은 손실이 누적된다. 1.5%는 1분봉의 평균 노이즈를 흡수하면서도 진짜 추세 이탈은 차단한다. |
| 익절 켜기 + 2.5% | 1.0%는 거래 수수료(왕복 0.1%) + 슬리피지 후 실효 0.7%에 불과. 평균 손실 -0.875%보다 작으므로 산수상 무조건 진다. **2.5%여야 한 번 익절이 한 번 손절을 충분히 만회한다.** |
| 장기 보유 차단 (90분) | 오늘 70분 보유 -5.226% 사례, 6/20일 6시간 보유 -3.12% 사례를 직접 차단. 90분 동안 -0.3% 미만의 손실이 계속되면 그 자리는 추세가 죽은 자리 — 빠져나오는 게 합리적. |
| 급등 필터 (2.5%) | EMA 골든 크로스는 1분봉에서 시간당 수 차례 발생. 직전 변동성이 2.5% 이상인 진짜 추세에서만 매수하면 노이즈 진입을 차단할 수 있다. |
| 양봉 매수 | 음봉(직전 봉이 하락 마감)에서 매수 = 추세 약함. 양봉 확인은 "지금 막 상승이 시작됐다"는 컨펌. |
| 트레일링 임계 15% | 30%는 사실상 발동되지 않는 수치. 15%로 낮추면 익절 후에도 추가 상승을 자동으로 추적할 수 있다. |

## 6️⃣ 자주 묻는 질문

### Q1. 손절 1.5%는 너무 큰 것 아닌가? 작게 잡을수록 안전한 것 아닌가?

A. 1분봉의 평균 변동성은 0.3~0.5% 수준입니다. 손절 0.5%는 평균 노이즈 한 봉이면 발동돼서, 결국 "모든 거래가 노이즈에 컷 → 작은 손실이 반복 누적"되는 결과를 만듭니다. 1.5%는 진짜 추세가 이탈했을 때만 컷합니다.

### Q2. 익절 2.5%까지 기다리지 않으면 익절을 더 자주 할 수 있지 않나?

A. 익절 1.0%는 수수료와 슬리피지를 빼면 실효 약 0.7%입니다. 평균 손실 -0.875%보다 작아서, 산술적으로 거래를 많이 할수록 손실이 커지는 구조입니다. 2.5%여야 한 번의 익절이 한 번의 손절을 충분히 메웁니다.

### Q3. 장기 보유 차단 90분은 너무 짧지 않은가?

A. 1분봉 + EMA 60/200 전략은 90분 안에 추세가 명확해집니다. 90분 동안 -0.3% 미만의 손실이 계속되면 그 자리는 "추세가 죽은 자리"이며, 손실이 더 커지기 전에 빠져나오는 게 합리적입니다.

### Q4. 급등 필터를 켜면 매수 빈도가 너무 줄어들지 않나?

A. 진단 데이터를 보면 28일간 매수 평가가 27,762건 발생했고 실제 매수는 190건(0.7%)이었습니다. 급등 필터는 이 0.7% 중에서도 노이즈성 진입을 더 걸러낼 뿐 진짜 추세 진입은 통과시킵니다. **거래 빈도가 아니라 거래 품질이 누적 손익을 결정합니다.**

### Q5. 한꺼번에 8개 다 바꾸기 부담스러운데 단계적으로 하면 안 되나?

A. 부분 적용 시 두 가지 문제가 생깁니다:
1. **효과 측정 불가** — 어느 항목이 효과를 냈는지 분리할 수 없습니다.
2. **부분 적용은 오히려 더 위험할 수 있음** — 예를 들어 손절만 켜고 장기 보유 차단을 끄면, 작은 손실이 반복 컷되어 누적 손실이 더 커질 수 있습니다.

8개는 세 가지 축(수익/손실 균형 + 진입 품질 + 보유 시간 보호)이 함께 맞물려 설계됐기 때문에 **함께 적용해야 본래 의도한 효과**가 납니다.

### Q6. 이 권장사항이 미래에도 계속 유효한가?

A. 아니요. 시장 변동성이 바뀌거나 다른 코인으로 전환하면 같은 숫자가 맞지 않을 수 있습니다. 그래서 §5 일주일 모니터링 후 추가 조정이 필요하고, 코인을 바꿀 때는 새로운 진단 보고서가 필요합니다.
