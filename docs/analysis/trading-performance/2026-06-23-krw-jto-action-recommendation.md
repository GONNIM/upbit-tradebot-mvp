| audit_settings 분당 적재 | 정상 ✓ |

→ 6/22~6/23에 작업한 강화 작업(SP1~SP6)은 **모두 정상**이다. 더 이상 인프라가 손실의 원인이 아니다.

### 1-2. 그런데 왜 손실이 났는가 — 오늘(6/23) 단일 거래

```
18:56:14 BUY  @ 995원 (EMA Golden Cross)
20:13:09 SELL @ 943원 (EMA Dead Cross)
보유   = 70분
손익   = -5.226%  ❌
```

**왜 -5.226%까지 흘러갔는가?**

| 매도 트리거 | 활성 여부 | 결과 |
|---|---|---|
| Stop Loss | ❌ **OFF** | 손절 발동 안 함 |
| Take Profit | ❌ **OFF** | 익절 발동 안 함 |
| Trailing Stop (30%) | ✓ ON | 30% 도달 못 함 → 무의미 |
| EMA Dead Cross | ✓ ON | **이 하나만이 작동** → 지연 매도 |

→ **매도가 EMA Dead Cross 한 가지에 전적으로 의존**하는 구조다. EMA는 지연 지표이므로 가격이 한참 떨어진 다음 발동된다.

### 1-3. 21:49 조작이 무엇을 의미하는가

오늘 -5.226% 손실 직후, 사용자는 21:49:27에 conditions를 저장하면서:

```
변경 전:  sl_pct=1.0%,  tp_pct=2.5%
변경 후:  sl_pct=0.5%,  tp_pct=1.0%
```

→ **숫자만 더 작게 줄였지만 `stop_loss` 토글은 여전히 OFF**다. 토글이 꺼져 있으면 이 숫자는 트리거에 사용되지 않는다 — **의미 없는 조정**이다.

손실을 본 직후의 자연스러운 반응은 "더 안전하게 하자"인데, 실제 조작은 안전망 자체가 꺼진 상태를 유지한 채 사용되지 않는 숫자만 줄인 것이다. 이 인식의 격차가 가장 큰 문제다.

### 1-4. 받아들여야 할 사실 세 가지

1. **현재 매도 안전망(SL/TP/stale)은 모두 꺼져 있다.** 가격이 -10%, -15%로 떨어져도 EMA Dead Cross 전까지는 매도되지 않는다.
2. **숫자(0.5%)를 바꿔도 토글(OFF)이 꺼져 있으면 효과가 없다.** UI는 두 개를 별개 항목으로 관리한다.
3. **진단 §8 권장 8개 항목 중 0개가 적용되어 있다.** 권장은 6/22 작성됐고 강화 작업이 끝났으나, conditions 적용은 별개 액션이며 사용자만이 할 수 있다.

→ **이 셋을 명확히 인식한 다음에야 §2~§3의 권고가 의미를 가진다.**

## 5️⃣ 사용자가 자주 가질 수 있는 의문 (FAQ)

**Q1. SL 1.5%는 너무 큰 것 아닌가? 작게 잡을수록 안전한 것 아닌가?**
A. 1분봉의 평균 변동성은 0.3~0.5% 수준. SL 0.5%는 평균 노이즈 한 봉이면 발동된다. 결과적으로 모든 거래가 "노이즈에 컷 → 작은 손실 × 빈도"로 누적된다. 1.5%는 진짜 추세 이탈만 컷한다.

**Q2. TP 2.5%까지 기다리지 않으면 익절을 더 자주 할 수 있지 않나?**
A. TP 1.0%는 commission/슬리피지 후 실효 0.7%. 평균 손실 -0.875%보다 작으므로 산수상 무조건 진다 (R/R < 1). 2.5%여야 R/R ≥ 1.5 성립.

**Q3. Stale Position 90분은 너무 짧지 않은가?**
A. 1분봉 EMA 60/200은 90분 안에 추세가 명확해진다. 90분 동안 -0.3% 미만의 손실이 진행 중이면 그 자리는 추세가 죽은 자리. 손실 더 확대되기 전에 빠져나오는 게 합리적.

**Q4. Surge Filter ON하면 매수 빈도가 너무 줄어들지 않나?**
A. 진단 §3 데이터 — 매수 평가 27,762건 / 실제 매수 190건 (0.7%). Surge filter 2.5%는 이 0.7% 중 노이즈 진입을 더 걸러낼 뿐 진짜 추세 진입은 통과한다. **거래 빈도가 아니라 거래 품질이 누적 손익을 결정**한다.

**Q5. 한꺼번에 8개 다 바꾸기 부담스러운데 단계적으로 하면 안 되나?**
A. 부분 적용은 효과 측정이 어렵다 (어느 항목 효과인지 분리 불가). 또한 SL만 켜고 stale 끄면 -1.5% 컷이 반복되어 오히려 손실이 커질 수 있다. **8개는 R/R 1.5 + 진입 품질 + 보유 시간 보호의 3축으로 함께 설계된 권고**다.
