# 질의: 사용자가 PC 한 페이지(A)를 고르고 구버전 구역까지 넣고 싶다며 모바일은 어떻게 되는지 물었고, 답과 범위 결정안을 올리려 합니다

**지금 단계:** 요구 정리 (범위 결정 요청)
**다음에 하려는 일:** 사용자 질문 「구버전 구역까지 넣고 싶은데... 모바일 버전은 어떻게 되는가?」에 답하고 두 가지를 묻습니다. (1) 모바일 처리: 가(권고) 모바일은 지금 화면·탭 그대로 두고 새 구역은 PC 한 페이지에만 / 나 모바일에도 새 읽기 구역을 기존 탭 맨 아래에 붙임(배치 불변, 내용만 늘어남). (2) 구버전 구역 처리(권고안 하나로 승인 요청): 읽기 구역(매수 로그·매도 로그·상태/경고/에러 로그·엔진 상태 conditions·감사 로그·매매 설정 표시)은 이번에 넣고, 쓰기 구역(강제 매수·매도, 설정 저장, 설정 이력 등 단추)은 PC 에도 「2차 공개 때 열림」 비활성 단추로 같은 자리에 표시만(spec E10 유지). 승인 뒤 계획(구역별 데이터 출처·새 읽기 API·시험·EXPLAIN 재측정) → 구현 → 실측 → verifier·Fable → 승인.
