## 올리려는 제안 (1차 답변 반영본)
- **권고안 (가) 차트 탭만 넓게:** PC 도 휴대폰과 같은 index.html 을 연다(자동 이동 삭제). 홈·로그·운용 탭과 아래 탭 막대는 휴대폰 모양 그대로 가운데 휴대폰 폭(약 480px). 홈 맨 위 기본 블록(매매 중지/재개·자산 3칸)은 그대로 있고, 480px 안에서는 자산 3칸이 세로 1열로 바뀐다. 차트 탭을 누르면 차트 칸만 창 전체 폭으로 넓어지고 높이는 창 높이에 맞춘다(위 머리·아래 탭 막대를 뺀 높이, 방법은 계획서에서). 봉 수는 200 그대로. 백테스터는 휴대폰처럼 아래 링크로 들어간다. 모바일(640px 이하)은 바꾸지 않는다.
- (나) 모든 탭을 휴대폰 폭으로 두고, 차트 칸에 「크게 보기」 단추 → 누르면 차트가 화면 전체를 덮고 「닫기」·Esc 로 돌아온다.
- (다) 모든 탭을 창 전체 폭으로 늘리고 차트 높이만 키운다.
- 그대로 둠: 지금 PC(백테스터 + 기본 블록).
- 세 안 공통: 휴대폰 가로 화면·641px 이상 태블릿은 PC 배치가 된다(기준은 창 폭 640px).
- 작업 크기(세 안 공통, (나)는 단추 하나 더): index.html 넘김 1줄 삭제 + style.css 몇 줄 + 기본 블록 3칸 격자 규칙 + 차트 높이 계산 + 시험 3개(`tests/v2/js/basic.test.mjs:367·375·445`) + spec 3곳(`spec.md:19·119·242`)·계획서 1곳(`plan-pc-basic-20261025.md:114`) 개정. Python·엔진·API 변경 0. 배포는 tradebot-v2 재시작만(엔진 재시작 없음).
- 업비트 호출: 엔진·서버 IP 의 업비트 호출은 0 그대로. 지금 PC 브라우저는 업비트를 부르지 않는데, 바뀐 뒤에는 PC 차트 탭에서 모바일과 같은 양(200봉·30초)을 투자자 IP 로 부르게 된다(PC 추가분). 실패해도 화면에 「갱신 실패」만 뜬다.
- 함께 정할 것: 봉 수(200 그대로 권고 — 더 늘리면 업비트 호출이 여러 번), A′ 발송을 이 변경 반영 뒤로 미루고 문장을 고칠지(권고), PC 의 백테스터 화면은 지금 그대로(권고), 백로그 1025-17(정적 파일 Cache-Control — 옛 화면 캐시 방지)을 이번에 묶을지(권고: 묶음, 배포 뒤 강력 새로고침 안내도 함께).
