- 단계: 투자자 대화 등록(서버 `.env` 변경) + 시험 알림 1건(외부 발송) 실행 직전
- 규칙: `.claude/context/project-rules.md` 「서버 비밀 파일 권한 규칙」 1122-01 ㉠ 줄, 「투자자 연락 원칙」 3번

| # | 사실 | 확인/추정 | 근거 |

| 1 | 투자자가 봇 「시작」을 눌렀다고 운영자에게 알려 옴(시각 전달 없음) | 확인(사용자 글 11/23 19시대) | 대화 |
| 2 | 서버 목록 읽기 11/23 19:51:52: 봇 @upbit_tradebot_bot, 개인 대화 1개(11/23 12:40, 「글 보냄」 = 마지막 글이 /start 가 아님), 운영자 채팅 표시 없음, 지금 등록 없음 | 확인 | scratchpad key9_list_read.sh 출력 |

| 8 | 「시작」 뒤 24시간 안이어야 목록에 보임 → 11/24 12:40 전 | 확인 | register 스크립트 머리 주석 |

### 다음에 하려는 일
- 운영자에게 「목록 1번이 투자자 본인인지」 확인과 등록 승인을 받은 뒤, 운영자가 `! ssh … 'bash -s' < scratchpad/key10_register.sh` 실행.
- key10_register.sh: 등록 전 `ls -la .env*` → 목록 개수가 정확히 1이 아니면 멈춤 → `--pick 1`(출력에서 이름 지움) → 등록 뒤 `ls -la .env*`·줄 수 → `--test-investor`.
- 그 뒤 투자자 수신 확인(운영자 경유), HANDOFF·연락 기록(시험 알림은 키 발급 부탁 종류의 준비 — 기록할지 질문) 갱신.

## 답변

### 1회째 답 (요지)
- 판정: 수정 후 진행
- 막음 1: 이름에 괄호가 있으면 sed 가 이름 일부를 남김 → 「(새로 넣음|바꿈)」 앞을 모두 지우는 모양으로
- 막음 2: 개수만 셈 → 1번 줄 시각 「· 11/23 12:40 ·」까지 확인, 목록은 한 번만 받음
- 막음 3: 파이프 때문에 --pick 실패를 못 잡음 → PIPESTATUS·등록 뒤 줄 수 확인, 실패면 시험 알림 전 멈춤
- 권고: 서버 HEAD 출력 · 등록 뒤 cron 끝 줄 investor=0/0 확인 · 24시간 근거(텔레그램 getUpdates 문서)
- 사실 확인: 오늘 21:05 cron 은 투자자에게 알림을 보내지 않음(30일 이하부터) · 「글 보냄」은 마지막 글이 /start 가 아니라는 뜻 · 운영자 채팅 값이 .env 밖에만 있으면 표시가 안 붙을 수 있음 → 운영자 이름 확인으로 막음
- 사용자에게 물을 것: 1번 이름이 투자자 본인인지 · 시각 대조를 이름 확인으로 갈음할지 · 시험 알림을 연락 기록에 적을지
- 처리: 막음 3건 고침, 권고 1(HEAD) 반영, 로컬 bash 시험 통과
