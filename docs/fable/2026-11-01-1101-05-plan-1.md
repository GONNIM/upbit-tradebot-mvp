1. 모든 시작 경로:
   - 직접 호출 6곳과 `restart_engine` 경유 호출이 모두 `start_engine` → `_start_engine_locked`(:347)를 지납니다.

   - MODE-LOCK 뒤에 두면 정상 시작을 가리지 않습니다.
   - `engine/engine_runner.py:128` 옛 이름 경로는 운영 코드가 부르지 않습니다.
2. 경보·문구·알림 끄기:
   - 신버전 30초 CRITICAL 과 구버전 거절 때 300초 WARNING 이 짝입니다. HTTP 는 잠금 밖에서 보냅니다.
   - 실패 알림은 이 사유에서만 끕니다. 「아무도 안 누르면 경보 없음」 한계는 이미 적혀 있습니다.

4. 도구 자격증명:

   - `config.py:10-12` 는 `st.secrets["UPBIT_ACCESS"]` 가 있으면 `load_dotenv()`(:14-16)를 부르지 않습니다.
   - 서버는 업비트 키가 secrets.toml, 텔레그램·운영자 키가 `.env` 에 있습니다(요청서 :20·:43, 보고 :160).
