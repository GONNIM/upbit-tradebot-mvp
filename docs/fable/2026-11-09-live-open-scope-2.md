## 고친 순서 (막음 1 반영)
① 투자자 정정 안내(사용자 발송) → 보낸 뒤 통보 기록에 클레임 답변 1줄
② 새 일 1행 등록(하위 순서에 번호 없음)
③ 계획서: 업비트 시장가 체결 응답 공식 문서 확인 + 활성 파일·적용본·운용자산 모드 분리 + 조건 1·2·3·4·7·10 + 실계좌 복귀 경로 + 시장가 재시도 이중 매수 방지. 조건 5·6·9 는 함께 처리 또는 기록
④-1 (배포 없음, 사용자 승인 뒤) 엔진 밖 일회용 스크립트를 서버에서 1회 실행: 엔진 종목이 아닌 종목으로 최소 금액(약 6,000원) 시장가 매수 → 체결 확인 → 전량 시장가 매도, 응답 원문을 저장. 목적: ③ 의 체결 처리 설계 입력. 실패할 이유: 실측 주문이 잔고 동기화에 앱 매수로 기록될 수 있음(사실 4), 미체결·잔량 남으면 사용자가 앱에서 정리해야 함. 시점은 엔진 미보유·매매 없는 시간, 사용자 입회.
③′ 구현·시험 (④-1 응답을 시험 자료로 사용)
⑤ 배포: 막음 해제는 금액 상한을 둔 채로(사용자가 정한 작은 운용자산으로 먼저) 진행, 사용자 입회로 실제 엔진 경로 소액 1거래 확인
⑥ 상한을 풀고 투자자 통보(체감 변경)
