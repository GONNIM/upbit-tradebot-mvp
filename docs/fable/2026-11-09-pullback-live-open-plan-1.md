# 답변 요지 (Fable, 원문의 판정·지적을 PO 가 옮겨 적음)

**1회째 판정:** 수정 후 진행. 코드 줄·업비트 공식 문서 대조는 맞음. 막음 1건: Task 7 규칙 1 의 같은 식별자 재시도가 식별자 재사용 불가 규정과 어긋남.
- Q8 은 ① 로 올려도 됨(② 는 첫 실계좌 거래 뒤 후속). 일정은 코드로 더 줄일 곳이 2시간 이내이고, 달력을 정하는 것은 Q1~Q8 답 시각 · 소액 실측 입회(11/12 안) · 입회 소액 거래 시각 세 가지.
- 권고: 입회 금액과 비율 하한 대조 / 로컬 가지 커밋(규칙 때문에 패치 보존 유지) / Q4·Q8 줄 보강 / 2절 trades·identifier 사실 / 콜백 우편함을 봉 맨 앞 조회로 단순화(구현 시작 때 코드로 보고 정함).

**2회째 판정:** 진행. D5·Task 7 규칙 1·시험 이름 수정 확인. 권고 2건(pending_json 식별자 목록, 이중 접수 시 halted + CRITICAL) 반영.
