# 질의: Ver2 1단계(백테스터 로컬 구현 · 업비트/바이낸스 비교)를 마쳤고, 사용자에게 1-5 비교 결과를 보고하려 합니다

**지금 단계:** 1단계 구현 끝 (사용자 보고 직전)
**다음에 하려는 일:** 사용자에게 1-5 비교 결과와 아래 결정 2건을 올립니다. 사용자가 정하기 전에는 커밋·push·투자자 발송을 하지 않습니다. 사용자가 「로컬 커밋」을 고르면 1단계 코드·시험·비교 근거를 한 커밋으로 묶습니다(`pages/dashboard.py` 버전 갱신 포함 — v2/static 은 런타임, 무시 목록에 걸린 근거 파일은 `git add -f`, 커밋 전 `git diff --staged` 비밀값 검사, heredoc 없이 `git commit -F`). push 는 하지 않습니다(push 전 자동 검사가 save.test 3개 실패로 막음 — 2단계에서 풀림). 투자자 PDF 는 사용자가 비교 결과를 확인한 뒤 따로 만들고, 보내기 전에 Fable 질의를 따로 합니다.

**검증 이력:** verifier 1단계 1회째 「수정 후 승인 권고」(지적 11) → 고침 → 2회째 「사용자 보고 가능」(새 문제 없음, 낮은 지적 4 중 2건은 고침 — 12절 실패 원인 문장, 측정 스크립트 주석).
