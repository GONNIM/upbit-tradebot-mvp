### 올릴 권고
1. 등록은 지금 따로 한다(같은 .env 한 줄 · 키 만료만 먼저 받음 · 24시간 기한 때문).
2. notifier.send() 에 「투자자 사본」: TELEGRAM_CHAT_ID_INVESTOR 가 있고 이번에 보낸 채팅과 다르면 같은 글을 한 번 더 보냄. 등급·운영자 전용 모두 포함(사용자 「모두」). 매매 스레드가 늦어지지 않게 사본은 뒤 스레드로. 키 만료 점검의 직접 발송과 겹치지 않게 함.
3. project-rules 1122-01 ㉠ 줄을 사용자 새 지시로 고침. 투자자 체감 변경 안내 대상.
4. 배포는 엔진 재시작 → 보유 없을 때.
