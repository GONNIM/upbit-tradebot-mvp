# 투자자 안내 글 초안 (1122-01 · 배포 전 · 메신저) — 체감 변경 통보

> **대체됨 (11/22):** 사용자 요청으로 이 글과 텔레그램 가입·봇 구독 매뉴얼을 합친 PDF(investor-guide-20261122.pdf)를 보낸다. 1122-01 ㉠ 적용으로 아래 4번(알림은 운영자만)은 맞지 않는다. 이 글은 보내지 않는다.

투자자님, 대시보드 홈 화면에 업비트 키 만료일 배지가 생깁니다. 지난 11/19 처럼 키가 만료되어 주문이 거절되는 일을 미리 막으려는 것입니다.

1. 홈 화면 배지 줄 맨 끝에 「업비트 키 · 2027-11-19 만료 (362일 남음)」이 회색으로 보입니다. 남은 날 수는 매일 줄어듭니다.
2. 만료 30일 전부터는 노란색, 7일 전부터와 만료된 뒤에는 빨간색으로 바뀝니다.
3. 만료일을 이틀 넘게 확인하지 못하면 빨간색 「업비트 키 만료일 확인 안 됨 (마지막으로 받은 만료일 …)」이 보입니다. 이때는 운영자가 확인합니다.
4. 만료가 다가오면 운영자가 텔레그램으로 알림을 받고, 투자자님께 새 키 발급을 따로 부탁드리겠습니다. 키는 투자자님이 업비트에서 발급하셔야 합니다. 키 값은 메신저에 적지 말아 주세요. 전달 방법은 그때 따로 안내드리겠습니다.
5. 매매 방식과 설정은 바뀌지 않습니다.

적용 뒤 화면을 새로고침하시면 보입니다.
