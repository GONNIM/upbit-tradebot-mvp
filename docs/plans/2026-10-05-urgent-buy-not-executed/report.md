## 4. 감사 로그 페이지 표시

- **BUY 평가 표** (`audit_buy_eval`): id 76229 는 `overall_ok=1`, 메모 `🟢 BUY | Golden | bar=332` 로 보인다. 이 행에는 주문 결과(취소)를 적는 칸이 없고 `pending_*`·`validation_*` 열도 비어 있다 (`evidence/audit-buy-eval-76229.txt`).
- **거래 기록 표** (`audit_trades`): 미체결 취소는 체결이 아니라 행을 남기지 않는다 → 10-04 14:15 봉에 대응하는 거래 행이 없다. (`*_REJECTED` 는 거래소 거절만 기록하며, 시간 초과 취소는 해당하지 않음.)
- 결과: 투자자 화면에는 "🟢 BUY 신호 → 거래 없음" 으로 보인다. 실제로는 주문이 나갔다가 미체결로 취소됐다는 사실이 화면 어디에도 없다. (텔레그램 "미체결 취소" 알림은 코드상 보내게 되어 있으나, 알림 모듈은 성공 시 로그를 남기지 않으므로 이번 조사로 발송 여부를 확정하지 못했다 — `[NOTIFY]` 경고 0건.)
