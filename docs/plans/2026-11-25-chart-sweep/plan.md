## 할 일
### A. 차트 탭 (chart.js · app.js · index.html · style.css)
- A1 표식 옆 시각·가격 글: 표식 자료의 text 「매수」「매도」는 그대로 두고, 그릴 때만 「매수 261124_1509 · 330」으로 붙임(KST). 「옆 글 보기」 켜고 끄기(기본 켬). 화면에 보이는 표식 수가 max(40, 폭/9)를 넘으면 글 숨김(백테스터 기준). 화면을 옮길 때 보이는 표식 수가 바뀔 때만 다시 그림. LW 는 표식 위·아래 한 줄 글이라 백테스터(두 줄·옆)와 똑같지는 않음 — 휴대폰 실측으로 겹침 확인
- A2 봉 정보 상자: 차트 아래 한 칸, 십자선 위치 봉의 시각·시가·고가·저가·종가·선 값. 휴대폰은 길게 눌러야 나오는 것으로 추정 → 실측 후 안내 글을 맞춤
- A3 전체화면 단추: CSS 로 화면 가득(.chart 높이 덮어씀) · 닫기 단추 · 탭 이동·뒤로 가기 때 자동 닫힘
- A4 봉 수 고르기: 400 / 1000 / 2000, 실제 목표 = max(고른 값, 전략 목표). 바꾸면 그 봉 수로 다시 모음(10초 간격 그대로 → 2000봉은 약 90초). 「최근 200봉」 글자 → 실제 모인 봉 수
- A5 「전체 봉 보기」 단추(fitContent). 휠·끌기·핀치는 지금 그대로 켜져 있음
- A6 색: 백테스터처럼 어두운 바탕·같은 캔들·선 색 (투자자 글 「백테스터 차트 모양」) — 정할 것 ㉠
- 그대로: 실제 매수·매도 표식만(백테스트 결과 안 넣음) · 30초 갱신 · 10초 요청 간격 · 선 계산
### B. 스윕 설명 접기 (backtester.html · bt_ui.js · style.css)
- B1 html:229 → 늘 보이는 한 줄 「1등 조합은 이번 기간에서만 최적입니다(과최적화 주의)」 + 접기 상자 「설명 펼치기 / 접기」(기본 접힘). 「최대 20,000개 조합」 글은 상자 안에 그대로
