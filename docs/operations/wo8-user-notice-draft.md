## 안내문 (초안)

안녕하세요. 자동매매 봇의 **강제 매수 동작이 하나 바뀌었습니다**. 이전에는 강제 매수 버튼을 누르면 항상 시장가로 즉시 체결됐지만, 이제는 **지정가 매수 설정이 켜져 있으면 강제 매수도 지정가로 발주됩니다**. 발주 후 **최대 5봉(현재 설정 기준 약 25분)** 동안 체결을 기다리며, 그 안에 체결이 안 되면 **자동으로 취소되고 텔레그램에 `[FORCE] 강제 매수 지정가 미체결 → 자동 취소` 알림이 갑니다**. 이렇게 하면 급하게 시장가로 사는 것보다 **원하는 가격에 체결될 가능성**이 높아지고, 슬리피지도 줄어듭니다.

**즉시 체결이 필요한 상황이면 매수/매도 조건 페이지에서 지정가 매수 설정을 끄시면 됩니다**. 그러면 강제 매수는 예전처럼 **시장가로 즉시 체결**됩니다. 대시보드에서 강제 매수 버튼 아래에 지정가 매수 활성 상태 안내가 표시되니 발주 전에 확인해 주세요.

한 가지 여쭙습니다 — 이전에 요청드렸던 **평소 매수 방식 선호** 회신을 다시 부탁드립니다. **지정가**는 원하는 가격 보호가 되는 대신 체결이 불확실하고, **시장가**는 즉시 체결되는 대신 급등 시 슬리피지를 감수해야 합니다. 두 방식 중 어느 쪽을 기본으로 두시는 게 편하신지 알려주시면 그에 맞춰 설정을 유지하겠습니다.
