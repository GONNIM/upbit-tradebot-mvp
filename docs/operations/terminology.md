# 사용자 노출 용어 기준 (WO-11)

- 제정일: 2026-09-30
- 적용 범위: 화면(pages/), 텔레그램 알림, `logs` 테이블 메시지(대시보드 로그 표시), 감사 로그 페이지, 사용자 공지 문서
- 적용 제외: 코드 키, 로그 태그, 서버 로그(journal), 코드 주석

## 1. 정의 (4개)

| 용어 | 정의 |
|---|---|
| **시장가 매수** | 신호가 나면 시장가로 바로 삽니다. 봇 설정 "현재가 매수"를 끈 상태입니다. |
| **현재가 매수** | 신호 봉의 마감가로 주문을 걸고 N봉 기다립니다. 미체결이면 자동 취소됩니다. N은 설정 페이지의 "현재가 매수 대기 봉 수"(1~5)입니다. 강제 매수도 이 설정을 따릅니다. |
| **시장가 매도** | 봇의 매도 방식입니다. 옵션은 없습니다. 매도 조건(손절, 트레일링, 데드크로스 등)은 "언제 팔지"만 정하고, 체결은 항상 시장가입니다. |
| **앱 지정가 주문** | 업비트 앱에서 사용자가 직접 가격을 정해 넣은 주문입니다. 봇의 주문이 아닙니다. 앱 지정가 매도 주문이 걸려 있으면 그 수량이 묶여 봇의 매도가 거래소에서 거절될 수 있습니다. |

## 2. 코드 키 ↔ 화면 용어 대응표

| 코드 키 / 식별자 | 화면 용어 | 비고 |
|---|---|---|
| `buy.fixed_price_buy_enabled = true` | 현재가 매수 | 키 이름 유지 |
| `buy.fixed_price_buy_enabled = false` | 시장가 매수 | 키 이름 유지 |
| `buy.fixed_price_buy_wait_bars` | 현재가 매수 대기 봉 수 | 키 이름 유지 |
| `UpbitTrader.buy_limit()` / Upbit `ord_type=limit` | 현재가 매수 주문 | 거래소 주문 형식은 지정가(limit) 그대로 |
| `UpbitTrader.buy_market()` / `ord_type=price` | 시장가 매수 | |
| `UpbitTrader.sell_market()` / `ord_type=market` | 시장가 매도 | |
| `meta.reason = force_buy` + 현재가 매수 켬 | 강제 매수(현재가) | 알림 `[FORCE]` 접두 유지 |
| Upbit `balance.locked > 0` (외부 주문) | 앱 지정가 주문으로 수량 묶임 | WO-9 (b) |
| `insufficient_funds_ask` | 주문 가능 수량 부족 — 업비트 앱에서 직접 넣은 지정가 매도 주문이 있는지 확인하세요. | WO-9 (a)/(e) |
| `insufficient_funds_bid` | 주문 가능 KRW 부족 — 업비트 앱에서 직접 넣은 지정가 매수 주문이 있는지, KRW 잔고가 충분한지 확인하세요. | WO-9 (a)/(e) |
| 로그 태그 `[FIXED-PRICE]`, `[BUY-LIMIT]`, `[LIMIT-FILL]` | (화면 노출 없음) | 태그 유지 — 운영 문서 grep 과 연동 |
| dedupe 키 `fixed_buy_*` | (화면 노출 없음) | 키 유지 |

## 3. 폐기 용어

| 폐기 용어 | 대체 | 예외 |
|---|---|---|
| 고정가, 고정가 매수 | 현재가 매수 | 없음 |
| 지정가 매수 (봇 옵션) | 현재가 매수 | "앱 지정가 주문", "업비트 앱에서 직접 넣은 지정가 … 주문"은 허용 |
| 지정가 (봇 주문 가격 라벨, 예: "지정가: 767 KRW") | 주문가 | 위와 같음 |

검사 규칙: `services/terminology.py` 의 `DEPRECATED_PATTERN` (= "고정가" 전부 + 앞에 "앱 " 또는 "직접 넣은 "이 없는 "지정가").

"현재가"는 가격 칸 이름(예: 감사 로그 BUY 평가의 `price` → "현재가")으로도 쓰입니다. 이것은 "지금 가격"이라는 뜻이며 폐기 대상이 아닙니다. "Fixed/Profit-based"는 Trailing Stop 방식 이름이며 매수 방식과 무관합니다.

## 4. 과거 기록 처리

- DB 에 이미 저장된 행은 고치지 않습니다. 2026-09-30 기준 폐기 용어가 저장된 곳은 `logs.message` 9행(`🎯 [LIVE 고정가] 지정가 매수 요청 …`)뿐입니다. `audit_trades.reason`, `orders.meta`, `audit_buy_eval`/`audit_sell_eval` 의 notes·checks 에는 0건입니다.
- 화면에 보일 때만 `services/terminology.display_text()` 로 바꿉니다.
  - 대시보드: `fetch_logs` 결과 전체 (매수·매도·상태·전체·에러 로그)
  - 감사 로그 페이지: BUY 평가, SELL 평가, 체결 표의 문자열 칸
