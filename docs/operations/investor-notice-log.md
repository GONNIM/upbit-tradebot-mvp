# 투자자 통보 기록

- 신설: 2026-10-01
- 근거: `.claude/context/project-rules.md` "투자자 연락 원칙" (v2.12, 2026-10-01 운영자 결정)

## 운용 규칙

1. 투자자에게 보내는 연락은 두 종류뿐이다. **(1) 클레임 답변** — 원인·손해 여부·근거를 한 번에. **(2) 체감 변경 통보** — 화면 용어·버튼 동작·알림 형식 등 투자자가 보거나 누르는 것이 바뀔 때만.
2. 내부 개선(조회·검증·플래그·재시작 경로 등)은 통보하지 않는다. 회신을 기다리지 않는다.
3. **체감 변경이 들어간 배포를 하면 이 표에 한 줄을 추가한다.** 칸: 날짜 · 종류 · 계기(WO·클레임) · 담긴 내용 · 근거 문서 · 발송 원문 보관 위치.
4. 배포 보고서에는 "체감 변경 있음/없음"을 적고, 있으면 이 표의 줄 번호를 인용한다.
