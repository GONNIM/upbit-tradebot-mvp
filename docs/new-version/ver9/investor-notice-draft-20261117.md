# 투자자 안내 글 초안 (1111-01 · 배포 전 · 메신저) — Fable 1회째 권고 반영판

투자자님, 답 주신 대로 대시보드 백테스터에 Ver9 를 반영했습니다. 곧 적용할 예정이라 바뀌는 점을 먼저 알려 드립니다.

1. 선물 백테스트(롱+숏) 단추가 생깁니다. 바이낸스 USDT 선물 시세와 펀딩비로 화면에서만 계산합니다. 화면을 열면 업비트가 먼저 골라져 있어 이 단추가 막혀 있고, 바이낸스를 누르면 쓸 수 있습니다. 실제 매매는 지금처럼 업비트 현물입니다.
2. 백테스터를 열 때마다(새로고침 포함) 기본값이 분할 1회 · 익절 3% · 손절 3% 로 채워집니다.
3. 「여러 설정 비교(파라미터 스윕)」가 Ver9 범위로 바뀝니다. 둔화 허용치 축이 더해지고, 「자세한 결과」 안에 월/주별 1등 조합과 상위 10개가 나옵니다. 요약 카드에는 60선 기울기와 둔화 허용치도 보입니다.
4. 차트는 끌어서 움직이고, 전체화면 · 전체 봉 보기 단추가 생깁니다.
5. 시세 출처를 바꾸면 앞의 결과가 지워집니다. 계산이 도는 동안에는 출처를 바꾸거나 다른 계산을 시작할 수 없습니다.
