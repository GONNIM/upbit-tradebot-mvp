2. 사용자 `!` 본 띄우기: `systemd-run --unit=deploy-1103 --collect -p User=root --setenv=HOME=/root /bin/bash /root/deploy-1103/run.sh`.
3. 스크립트: 정지선(HEAD=ee874a2, 미추적 5, tradebot 기동 11/03 01:42:07·NRestarts 0, v2 기동 11/01 14:21:31, 비밀 파일 600·사본 0, 전략 EMA, 로그 수준, journal 실패 표지 0, origin/main = 커밋 C) → 봉마다 보유 0·묶임 0·미체결 0·잔고 갱신 120초 안·새 audit BUY 없음·정체 매도 꺼짐·minute3·최근 5분 ERROR 0 → DB 백업(무결성 ok·600) → 다음 봉 재확인·경계까지 60초 이상 → `git merge --ff-only C` → `systemctl restart tradebot` → 기동 확인 → 첫 봉 2개·check_v2_unit, 3점 일치·새 코드 표식(STALE-CLOCK·STALE-PEAK)은 결과 파일에 기록(판정은 완료 보고에서 인용) → 「배포 완료」 알림 → 1시간 관찰 → 통과하면 백업 권한 정리 → 「1시간 관찰 통과」 알림.

6. 정지선 기대값(기동 시각 두 개·미추적 5·11/03 01:42:07 뒤 journal ERROR 0)의 1차 근거는 드라이런 「DRY stopline OK」 — 어긋나면 쓰기 없이 끝나고, 원인을 본 뒤 값을 고쳐 다시 검증.
