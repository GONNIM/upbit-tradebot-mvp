### P3 — 새 전략 엔진 (★ 엔진 매매 경로)
- T1 전략 등록: 엔진 허용 목록(결정 D1), `load_active_strategy`·생성 분기, 기본값 무변경. **활성 전략을 읽는 곳 전체 표(F19)** 와 PULLBACK 일 때 각 곳의 동작(엔진 = PULLBACK 로더, 구버전 화면 = T15 표시 경로, 로그인 이동 = 대시보드).

- 엔진 매매 경로 변경 범위가 큼(★ 파일 15개 안팎). 회귀는 게이트·일치 시험으로 막되 배포 뒤 24시간 관찰 + 첫 전환 운영자 입회.
